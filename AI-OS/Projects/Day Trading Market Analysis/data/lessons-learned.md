# Lessons Learned — dated, specific, actionable

The Journalist appends a dated lesson after every review. Lessons must be concrete
enough to change a future decision. Vague entries ("be careful") are not allowed.

---

### 2026-06-11 — Session 01 (baseline established)
- **Regime first.** Opened with Fear & Greed = 9 (Extreme Fear). Set the whole
  session to risk-off: 0.5% risk/trade, support-bounces only, no breakout chasing.
  *Keep doing:* always set the regime read before picking trades.
- **Liquidity gate earns its keep.** GHST was up +38% but trades only ~$68k/24h —
  rejected as an illiquid trap. *Lesson:* a big % move on tiny volume is a
  spread/slippage/ manipulation hazard, never a day-trade candidate.
- **Don't chase exhaustion.** STG was +53% on the day — rejected a momentum long
  as an exhaustion chase. *Lesson:* only revisit parabolic movers on a
  pullback-and-hold above a reclaimed level, never the spike.
- **R:R gate killed XRP.** The $1.123–$1.145 range scalp only offered ~0.88 blended
  R:R — below the 1.3 floor — so it was dropped despite a clean-looking range.
  *Lesson:* tight ranges usually fail the R:R math; require ≥1.3 before logging.
- **Concentration is hidden risk.** All three entries (BTC/ETH/SOL) are correlated
  majors. Sized each at 0.5% (not 1%) to keep effective net risk sane. *Lesson:*
  count correlation as concentration; discount size when ideas move together.
